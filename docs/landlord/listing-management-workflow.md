# Landlord Workflow: Listing Management

Landlords manage listings from the Landlord dashboard. A useful listing should have an accurate title, city, neighborhood, rent, deposit or fee details where supported, property type, bedrooms, bathrooms, amenities, and clear photos.

Editing a listing should keep the listing truthful and current. Landlords should avoid duplicate listings, misleading locations, inaccurate pricing, and photos that do not represent the property.

If a listing is pending or rejected, the landlord should open the listing status and follow the message shown there. RoomBay Assistant can explain the documented review checklist but must not override admin review.
