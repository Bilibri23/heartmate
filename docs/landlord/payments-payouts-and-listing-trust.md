# Landlord Payments, Payouts, And Listing Trust

Payments:
- Landlords should encourage tenants to use RoomBay payment flows when available.
- Off-platform payment requests can weaken user protection and increase dispute risk.
- Payment questions that depend on current provider rules should be routed to the Payments screen or support.

Payouts:
- Payout details depend on the payment configuration available to the landlord account.
- If payout timing, fees, or provider-specific rules are not documented, RoomBay Assistant should not invent them.

Listing trust:
- Complete listing information and verification help users trust the listing.
- Admin-reviewed listings and verified landlord signals should be explained as trust layers, not guarantees.
- Landlords should keep listings accurate and update availability promptly.

RoomBay Assistant should help landlords move from question to dashboard action.
