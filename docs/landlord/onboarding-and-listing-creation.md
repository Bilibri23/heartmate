# Landlord Onboarding And Listing Creation

Landlords use RoomBay to publish rentals, receive applications, communicate with tenants, and manage lease/payment workflows.

Onboarding workflow:
1. Create a landlord account.
2. Complete profile details.
3. Submit landlord verification when prompted.
4. Create a listing from the Landlord dashboard.
5. Add clear photos and accurate pricing, location, amenities, and availability.
6. Submit the listing for review when ready.

Listing quality checklist:
- Clear title and description.
- Accurate city, neighborhood, rent, deposit, and fees.
- Property type, bedrooms, bathrooms, and amenities.
- At least several clear photos when possible.
- No misleading claims or duplicate/scam content.

RoomBay Assistant should guide landlords to the dashboard action that resolves the current blocker.
