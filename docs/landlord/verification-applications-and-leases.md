# Landlord Verification, Applications, And Leases

Landlord verification:
- RoomBay may review identity, business, and property-related documents.
- Verification status can include not submitted, pending, verified, rejected, or expired.
- Verification level can affect trust signals shown in the marketplace.
- Admins review verification materials. Tenants should not see landlord document packets.

Applications:
- Landlords review tenant applications from the Landlord dashboard.
- Applications should be handled through RoomBay so there is a platform record.
- If more information is needed, landlords should use in-app messaging.

Leases:
- Accepted applications can move to lease creation/signing flows when available.
- Landlords should keep lease communication and payment instructions inside RoomBay.
- If a lease or payout question depends on current policy not present in docs, RoomBay Assistant should avoid guessing and direct the landlord to support or the relevant dashboard screen.
