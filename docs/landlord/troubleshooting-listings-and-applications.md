# Landlord Troubleshooting: Listings and Applications

If a listing is pending review, the landlord should open the Landlord dashboard and check the listing status. Admin review may be required before a listing receives trust signals or becomes fully visible.

If a listing is rejected or needs edits, the landlord should follow the message shown on the listing review screen. RoomBay Assistant must not invent rejection reasons or override admin review.

If landlord verification is incomplete, the landlord should complete the verification steps shown in the dashboard. Verification can include identity, business, or property-related checks depending on the account and listing state.

If applications are not loading, the landlord should refresh the dashboard and check whether the listing is active. Persistent failures should be routed to support because they may indicate a backend or account-specific issue.

Landlords must not ask tenants to send government ID, selfie verification, or private verification packets outside the official RoomBay process.
