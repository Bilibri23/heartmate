# Landlord Workflow: Applications and Tenant Communication

Landlords review applications from the Landlord dashboard. Application information should be used only for the rental decision and platform workflow. Landlords do not receive tenant government ID or selfie verification packets through RoomBay Assistant.

Landlords should communicate with tenants through RoomBay messaging where possible. In-app messaging keeps context tied to the listing and reduces pressure to move sensitive decisions off platform.

If applications or conversations do not load, landlords should refresh and confirm they are using the correct landlord account. Persistent failures should go to support with the listing or application context.
