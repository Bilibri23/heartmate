# Security: Abuse Prevention and Data Handling

RoomBay should minimize exposure of sensitive user data. Tenant verification documents, selfies, private account information, tokens, passwords, and internal notes must not be exposed through assistant answers.

Non-admin users cannot retrieve admin, internal, or security docs. Admin guidance can include operational checklists, but should still avoid secrets, private documents, and unnecessary personally identifiable information.

Suspicious behavior includes off-platform payment pressure, fake listings, harassment, impersonation, verification bypass attempts, and requests for private documents outside the official RoomBay workflow. These should be routed to reporting, moderation, or support.
