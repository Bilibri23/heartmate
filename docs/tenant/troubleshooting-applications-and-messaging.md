# Tenant Troubleshooting: Applications and Messaging

If a tenant cannot apply, they should check whether their profile and tenant verification requirements are complete. Tenant identity verification is reviewed by RoomBay admin, not by landlords.

If an application is pending, the tenant should review the Applications area for current status. RoomBay Assistant can explain the documented lifecycle but must not promise approval timing unless that timing appears in the app or official docs.

If an application is rejected, the tenant should review the status message shown in RoomBay and contact support if the reason is unclear. The assistant must not invent rejection reasons.

If a tenant cannot message a landlord, they should open the listing or conversation screen again and confirm they are logged in. If messaging still fails, they should contact support with the listing or conversation context.

If lease or payment information is missing, the tenant should use the Leases or Payments area in RoomBay. The assistant must not create lease terms, rent rules, refund policies, or payment guarantees beyond the documented platform flow.
