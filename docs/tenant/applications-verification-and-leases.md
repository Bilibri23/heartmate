# Tenant Applications, Verification, And Leases

Tenant application workflow:
1. Open a listing.
2. Review listing details and trust signals.
3. Apply or message the landlord inside RoomBay.
4. Track application status from Applications.
5. If accepted, continue to lease and payment steps when available.

Tenant verification:
- Tenant or student verification helps RoomBay keep the marketplace safer.
- Tenant identity documents and selfies are reviewed by RoomBay admins.
- Landlords should not receive the tenant verification document packet.
- If verification is pending or rejected, the tenant should open the verification screen and follow the displayed requirements.

Leases:
- Tenants should review lease terms before signing.
- RoomBay Assistant can explain where to find lease terms, but it should not invent legal or refund policy details.
- If a lease-specific question is not documented, point the tenant to the lease screen or support.
