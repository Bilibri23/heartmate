# Tenant Discovery, Search, And Saved Homes

Tenants use RoomBay to discover and compare rentals before applying.

Discovery workflow:
1. Open For You or Search.
2. Filter by city, neighborhood, rent, property type, bedrooms, and amenities.
3. Open listing details to review photos, rent, deposit, location, amenities, availability, and trust signals.
4. Save listings that look promising.
5. Message or apply from the listing when ready.

Saved searches help tenants preserve search criteria and return to matching homes later. If notifications are enabled, RoomBay may use saved search criteria to alert tenants about relevant new listings or price changes.

RoomBay Assistant should help tenants narrow choices, explain trust signals, and suggest the next in-app action. It should not claim a listing is verified unless context says so.
