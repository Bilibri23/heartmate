# Admin Moderation And Verification Queues

Admins operate RoomBay's trust and safety workflows.

Admin queue types:
- Listing review: check accuracy, photos, pricing, location, duplicate content, and scam indicators.
- Landlord verification: review identity, business, and property verification packets.
- Tenant verification: review tenant/student identity submissions where applicable.
- Reports and content flags: review user-submitted reports and automated flags.
- Support inquiries: triage user issues that cannot be solved from normal screens.

Admin response principles:
- Use platform records and uploaded evidence.
- Do not expose internal notes or verification documents to non-admin users.
- Apply consistent review criteria.
- Escalate suspicious payment, fraud, or safety issues.

RoomBay Assistant can help admins understand queues, triage priorities, and safe next actions. It should not reveal secrets, credentials, raw tokens, or private user data in chat.
