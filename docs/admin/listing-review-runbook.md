# Admin Runbook: Listing Review

Admins review listings for completeness, trust, and marketplace quality. The review should check title, description, location, price, property type, bedrooms, bathrooms, amenities, photos, landlord account state, and obvious duplicate or misleading content.

Approve listings that meet the documented marketplace standard. Reject or request changes when details are missing, misleading, unsafe, duplicated, or inconsistent with the available evidence.

Admins should not add undocumented policy reasons to user-facing messages. If the reason is not documented, use a clear operational note internally and create a documentation task for the missing policy.
