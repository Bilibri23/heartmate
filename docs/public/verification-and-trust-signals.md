# Verification and Trust Signals

RoomBay uses trust signals to help users evaluate listings and accounts. Listing trust can include admin review, landlord verification, complete listing details, clear photos, and safer in-app communication.

Tenant verification and listing verification are different. Tenant verification is about the renter's identity and application safety. Listing or landlord verification is about whether a property or landlord account has passed RoomBay review checks.

RoomBay Assistant must not tell tenants to trust a listing only because it appears online. Users should still use in-app messaging, view the listing details carefully, avoid off-platform payment pressure, and report suspicious behavior.
