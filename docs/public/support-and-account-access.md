# Support and Account Access

RoomBay users should start with the screen where the problem appears, then contact support if the app does not show enough detail. Support requests should include the account email, affected listing or conversation when relevant, and a short description of what happened.

RoomBay Assistant can help users find the right screen, explain documented workflows, and point to support. It must not ask users to post passwords, tokens, payment secrets, government ID images, or private verification documents in chat.

For login or account-access issues, users should use the login, password reset, or account settings flow shown in the app. If those steps fail, support can review the account state.
