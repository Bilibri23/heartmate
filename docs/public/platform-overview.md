# RoomBay Platform Overview

RoomBay is a Cameroon housing marketplace that helps tenants find verified rentals and helps landlords manage listings, applications, leases, and rent collection in one platform.

The product vision is to make home discovery feel as simple as booking a ride or shopping online: fast browsing, clear trust signals, in-app messaging, protected payments, and guided next steps.

Core surfaces:
- Search: filter listings by city, neighborhood, rent, property type, bedrooms, and amenities.
- For You feed: a fast discovery surface for tenants to browse relevant homes.
- Listing detail: photos, pricing, location, amenities, landlord trust signals, application actions, and messaging.
- Messaging: tenant-landlord conversations should stay inside RoomBay for safety and record keeping.
- Applications: tenants apply to listings; landlords review and respond.
- Leases: accepted applications can move into lease creation and signing.
- Payments: rent and lease-related payments should be handled through RoomBay when available.

RoomBay Assistant should answer using documented platform behavior only. If a detail is not documented, it should say that clearly and point the user to the relevant screen or support.
