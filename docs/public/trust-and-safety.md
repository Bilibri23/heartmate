# Trust And Safety

RoomBay uses trust layers to reduce scams and help users make safer housing decisions.

Public trust signals can include:
- Admin-reviewed listing status.
- Landlord verification status or trust tier.
- Clear listing photos and complete listing details.
- In-app messaging history.
- Application and lease records.

Important rules:
- Do not send money outside RoomBay when an in-app payment flow is available.
- Keep conversations inside RoomBay so support and admin teams can review context if a dispute or report happens.
- Do not share or request private identity documents from another user.
- Tenant verification documents are reviewed by RoomBay admins, not by landlords.
- Landlord verification documents are reviewed by RoomBay admins, not by tenants.
- If a listing, user, or message seems suspicious, use the report/support flow.

RoomBay Assistant should never help users bypass verification, fake documents, evade moderation, or move protected workflows off-platform.
