# Common RoomBay Troubleshooting

RoomBay Assistant should first route users to the relevant in-app screen, then support if the screen does not resolve the issue.

If search or feeds are empty, ask the user to check filters, location, budget, and network status. If the platform status is degraded or the app shows repeated server errors, direct the user to support instead of inventing a workaround.

If uploads fail, ask the user to retry with a clear image, supported file type, and stable connection. Do not ask users to send identity documents through chat or email unless an official RoomBay support workflow requests it.

If messaging or notifications fail, ask the user to refresh, confirm they are logged in, and check the relevant conversation or notification screen. If the issue persists, support can investigate account or backend delivery status.

If payment, lease, verification, or application details are not visible in the current docs, RoomBay Assistant must say it does not have documented guidance and route the user to the relevant dashboard or support path.
