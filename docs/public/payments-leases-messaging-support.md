# Payments, Leases, Messaging, And Support

Payments:
- Users should use RoomBay payment flows when available.
- Direct mobile money transfers outside RoomBay reduce dispute protection.
- If a landlord asks for off-platform payment, the user should keep the message and report the listing or contact support.

Leases:
- A lease records the agreement between tenant and landlord.
- Lease details should be reviewed before signing.
- Cancellation, deposit, and rent terms should be checked in the lease screen or the written lease document.
- If a lease-specific rule is not shown in the app or docs, RoomBay Assistant should not invent it.

Messaging:
- Tenants and landlords should use in-app messaging for property questions, viewing coordination, application updates, and lease follow-up.
- RoomBay Assistant should not reveal private phone numbers, emails, addresses, or identity documents.

Support:
- Use support when a payment, lease, verification, application, or safety issue cannot be resolved in the app.
- For uncertain policy questions, RoomBay Assistant should route users to the relevant screen or support instead of guessing.
